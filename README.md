# DragScroll

Приложение для строки меню macOS. Зажмите правую кнопку мыши и двигайте её — содержимое под курсором прокручивается в любую сторону.

## Возможности
- Прокрутка перетаскиванием правой кнопкой; обычный правый клик сохраняется.
- Инверсия движения.
- Выбор скорости (×0.1 … ×10), клавиша ускорения (Shift/Control/Option/Command/Fn) и её множитель.
- Красный курсор-«рука» на время захвата.
- Плавный переезд курсора на кнопку по умолчанию при появлении диалога.

## Сборка
```bash
./test.sh    # тесты логики
./build.sh   # build/DragScroll.app
```
Нужно разрешение «Конфиденциальность и безопасность → Универсальный доступ». Сборка по умолчанию подписана ad-hoc, поэтому после каждой пересборки разрешение нужно выдавать заново. Чтобы этого избежать, создайте самоподписанный сертификат подписи кода и соберите так: `SIGN_ID="Имя сертификата" ./build.sh`.

## Ограничения
Смена курсора вне окон приложения использует недокументированный вызов macOS и может не работать на некоторых версиях.
